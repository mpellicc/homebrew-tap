# mpellicc/homebrew-tap

Homebrew casks for my apps.

```bash
brew install --cask mpellicc/tap/codex-reset-radar
```

| Cask | App |
|---|---|
| `codex-reset-radar` | [Codex Reset Radar](https://github.com/mpellicc/codex-reset-radar): a menu bar app that tells you when a Codex usage reset is announced |

The apps are ad-hoc signed, not notarized, so macOS blocks the first launch: open
**System Settings → Privacy & Security** and click **Open Anyway**. You only do this once.

The release workflow of each app updates its cask here; don't edit versions by hand.
